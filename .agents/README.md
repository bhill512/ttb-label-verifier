# Agent notes

Short orientation files for anyone (human or AI) picking up this repo. Each is
under 500 tokens. Read `overview.md` first.

| File | Read it when |
|---|---|
| `overview.md` | You need to know what the app is for and what constraints shape it |
| `architecture.md` | You need to find where something lives or how a request flows |
| `matching-rules.md` | You are changing how a field is checked or a verdict is decided |
| `workflow.md` | You need to run, test or build the app, or regenerate samples |
| `gotchas.md` | Something behaves oddly, or before touching OCR or text matching |

Keep these current: if a change makes one of them wrong, fix it in the same commit.
The user-facing documentation is the root `README.md`.
